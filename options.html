Un site par ligne : domaine (sous-domaines inclus) ou domaine/chemin. Exemple : docs.google.com/spreadsheets

Raccourcis
  • Glisser : plage rectangulaire
  • Ctrl + clic / glisser : ajouter une plage (ou la retirer si déjà sélectionnée)
  • Shift + clic : étendre la plage courante
  • Alt + clic : colonne entière ; dans la 1re colonne : ligne entière
  • Ctrl + Alt + clic : ajouter (ou retirer) une colonne / ligne
  • Ctrl + C : copier · Échap : tout effacer
  • Clic sur l'icône de l'extension : activer / désactiver
